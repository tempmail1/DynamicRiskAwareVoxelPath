变量、输入、运算、Math 与格式化输出 #

从第一行 Java 到可交互的购物清单和复利计算。

1.1 Java 程序从哪里开始

Java 源文件中的 public class Main 必须与文件名 Main.java 一致。JVM 从签名固定的 public static void main(String[] args) 开始执行。每条普通语句通常以分号结尾；花括号界定代码块。

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
Python 对照动态类型
Python 写 age = 16；Java 要先声明类型：int age = 16;。Java 编译器会在运行前发现许多类型错误。

1.2 基本类型、String 与常量

Java 类型示例适用常见坑
intint count = 12;整数计数5 / 2 得到 2
longlong views = 3_000_000L;大整数literal 较大时加 L
doubledouble price = 8.75;一般小数计算不是精确十进制货币
booleanboolean ready = true;真假状态不是 True/False
charchar grade = 'A';单个字符单引号
StringString name = "Mina";文本对象双引号

不会改变的值用 final 表达意图，例如 final double TAX_RATE = 0.08;。变量名采用 lowerCamelCase，类名采用 UpperCamelCase，常量常用 UPPER_SNAKE_CASE。

1.3 Scanner 输入与换行陷阱

Scanner 从键盘读取数据。nextInt()/nextDouble() 不消费行末换行；紧接 nextLine() 时会读到空字符串。初学阶段最稳妥的策略，是整行读取后解析。

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.print("Your name: ");
        String name = scanner.nextLine().trim();
        System.out.print("Your age: ");
        int age = Integer.parseInt(scanner.nextLine());
        System.out.printf("Hello %s, next year you will be %d.%n", name, age + 1);
    }
}

1.4 算术、随机数、Math 与 printf

运算符包括 + - * / %。整数参与除法时结果仍是整数；至少一边转为 double 才保留小数。Math.pow、sqrt、abs、min/max、round 处理常见数学运算；Random 用于可复现或不可预测的课堂小游戏。printf 的 %s、%d、%.2f 分别格式化文本、整数、两位小数。

复利模型若本金为 (P)、年利率为 (r)、每年计息 (n) 次、持续 (t) 年，则 (A=P(1+r/n)^{nt})。程序中的百分比要先除以 100。
import java.util.Random;

public class Main {
    public static void main(String[] args) {
        double principal = 1_000.0;
        double annualRate = 4.5 / 100.0;
        int years = 3;
        double balance = principal * Math.pow(1 + annualRate / 12, 12 * years);

        Random random = new Random(2026); // 固定 seed，输出可重复
        int coupon = random.nextInt(5, 21);
        System.out.printf("Balance: $%,.2f | Coupon: %d%%%n", balance, coupon);
    }
}
常见错误"Age: " + age + 1 会先拼成文本，例如 Age: 161；应写 "Age: " + (age + 1)。输入非法数字会抛出异常，本章先保证按提示输入，异常处理在第 10 章系统学习。
自检：double average = 7 / 2; 为什么得到 3.0？
右侧先做整数除法得到 3，再转换为 double。写成 7.0 / 2 或 (double) 7 / 2 才得到 3.5。

String、条件判断、switch 与逻辑运算 #

让程序根据文本与条件做出可解释的选择。

2.1 String 是对象

String 提供 length()、charAt()、indexOf()、substring()、toUpperCase()、trim()、isEmpty() 等方法。字符串不可变：这些方法返回新 String，不会原地修改原值。

String email = "  student@example.com  ".trim();
int at = email.indexOf('@');
String user = email.substring(0, at);
String domain = email.substring(at + 1);
System.out.println(user.toUpperCase());
System.out.println(domain);
关键差异比较文本
Python 通常用 name == "Ada"；Java 必须用 name.equals("Ada") 或更安全的 "Ada".equals(name)。== 比较的可能是两个引用是否指向同一对象。

2.2 if / else if / else

条件必须是 boolean。分支从上到下判断，只执行第一条为真的分支。范围判断用 &&，二选一用 ||，取反用 !。短路求值使 text != null && !text.isBlank() 安全：左侧为假时不会调用右侧。

int score = 84;
String grade;
if (score < 0 || score > 100) {
    grade = "INVALID";
} else if (score >= 90) {
    grade = "A";
} else if (score >= 80) {
    grade = "B";
} else if (score >= 70) {
    grade = "C";
} else {
    grade = "Needs improvement";
}

顺序非常重要：如果先判断 score >= 60，95 分会在更宽的条件处提前命中。nested if 用于第二层依赖判断，但嵌套太深时应先验证非法输入或使用方法降低缩进。

2.3 三元运算符与增强 switch

三元运算符 condition ? valueWhenTrue : valueWhenFalse 适合非常短的二选一，不适合嵌套复杂规则。现代 Java 的 switch expression 能直接产生值，并避免传统 switch 忘记 break 的问题。

String level = "MEDIUM";
int bonus = switch (level.toUpperCase()) {
    case "EASY"   -> 5;
    case "MEDIUM" -> 10;
    case "HARD"   -> 20;
    default       -> 0;
};
String message = bonus > 0 ? "Bonus unlocked" : "Unknown level";

2.4 完整示例：温度转换器

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.print("Enter temperature: ");
        double value = Double.parseDouble(scanner.nextLine());
        System.out.print("Convert to C or F: ");
        String target = scanner.nextLine().trim().toUpperCase();

        String result = switch (target) {
            case "C" -> String.format("%.1f °C", (value - 32) * 5 / 9);
            case "F" -> String.format("%.1f °F", value * 9 / 5 + 32);
            default  -> "Unknown target unit";
        };
        System.out.println(result);
    }
}
常见错误0 <= score <= 100 在 Java 中非法，必须写 score >= 0 && score <= 100。字符串判断不要用 ==；switch 的输入最好先 trim().toUpperCase() 统一格式。
自检：为什么判断成绩要从最高档开始？
因为 else if 只进入第一个成立分支。先写较宽的低门槛会吞掉后面更高等级的判断。

while、for、break、continue 与嵌套循环 #

重复执行，同时证明循环一定结束。

3.1 选择正确的循环

结构何时使用典型问题
while不知道要重复多少次，以条件结束输入验证、猜数字
do-while至少执行一次再判断菜单程序
for次数或计数范围清楚从 1 到 10、遍历索引
enhanced for只需逐个读取数组/集合元素求和、打印
Python 对照range
Python 的 for i in range(0, 5) 对应 Java 的 for (int i = 0; i < 5; i++)。Java for 把初始化、继续条件和每轮更新写在同一行。

3.2 循环的四个问题

  1. 初始化：循环开始前状态是什么？
  2. 条件：什么时候继续？
  3. 更新：每轮怎样接近结束？
  4. 不变量：每轮开始时始终为真的关系是什么？

例如累计 (1+2+\cdots+n)：第 (i) 轮开始时，sum 保存 1 到 (i-1) 的和。循环结束时 (i=n+1)，所以 sum 就是目标。忘记更新变量会造成 infinite loop。

3.3 break、continue 与嵌套循环

break 立即离开最近一层循环；continue 跳过本轮剩余语句。它们适合明确的提前结束/过滤，但过多会让控制流难读。nested loops 中，外层每执行一次，内层完成一整轮；打印 (r\times c) 网格需要 (rc) 次输出。

for (int row = 1; row <= 3; row++) {
    for (int col = 1; col <= 5; col++) {
        if (row == 2 && col == 3) {
            System.out.print("X ");
            continue;
        }
        System.out.print(". ");
    }
    System.out.println();
}

3.4 完整示例：猜数字

import java.util.Random;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int answer = new Random().nextInt(1, 101);
        int attempts = 0;

        while (true) {
            System.out.print("Guess 1-100 (0 quits): ");
            int guess = Integer.parseInt(scanner.nextLine());
            if (guess == 0) {
                System.out.println("Game ended.");
                break;
            }
            if (guess < 1 || guess > 100) {
                System.out.println("Out of range.");
                continue;
            }
            attempts++;
            if (guess == answer) {
                System.out.printf("Correct in %d attempts!%n", attempts);
                break;
            }
            System.out.println(guess < answer ? "Too low" : "Too high");
        }
    }
}
避免无法退出每个 while 都应能回答“什么状态使条件变假？”使用 while(true) 时，必须清楚指出所有 break 路径。
自检：两层循环各执行 (n) 次，一定是 (2n) 吗？
若一层嵌套在另一层内部，总执行次数约为 (n\times n=n^2)；若两个循环前后并列，才约为 (n+n=2n)。

方法、参数、返回值、重载、作用域与 varargs #

把一大段 main 拆成可以命名、测试和复用的小任务。

4.1 方法签名与返回值

方法由访问修饰符、static（本章先使用）、返回类型、名称和参数列表组成。void 表示没有返回值；非 void 方法的所有正常路径都要返回正确类型。参数是方法内部的局部变量。

static double rectangleArea(double width, double height) {
    if (width < 0 || height < 0) {
        throw new IllegalArgumentException("dimensions must be non-negative");
    }
    return width * height;
}
Python 对照类型与重载
Python 函数参数通常不声明类型，而且不能仅靠参数类型做传统重载。Java 编译器根据方法名与参数类型/数量选择 overload；返回类型本身不能区分重载。

4.2 Java 是 pass-by-value

Java 总是按值传递。传 int 时复制整数；传对象时复制“引用这个值”。因此方法能借复制的引用修改同一个可变对象，却不能让调用者变量改为指向另一个对象。理解这一点可以避免把“对象引用按值传递”误说成 pass-by-reference。

4.3 重载、作用域与 varargs

static int max(int a, int b) { return a > b ? a : b; }
static double max(double a, double b) { return a > b ? a : b; }

static int sum(int... values) {       // 调用方可以传 0 到多个 int
    int total = 0;
    for (int value : values) total += value;
    return total;
}

重载要求参数列表不同；sum(int... values) 在方法内部把 varargs 当数组。varargs 必须是最后一个参数，一个方法最多一个。局部变量只在声明它的花括号范围内有效；不同作用域使用同名变量会造成 shadowing，初学时应避免。

4.4 完整示例：骰子统计

import java.util.Random;

public class Main {
    static final Random RANDOM = new Random();

    public static void main(String[] args) {
        int[] rolls = rollDice(5, 6);
        printRolls(rolls);
        System.out.printf("Total=%d, average=%.2f%n", sum(rolls), average(rolls));
    }

    static int[] rollDice(int count, int sides) {
        if (count <= 0 || sides < 2) throw new IllegalArgumentException();
        int[] results = new int[count];
        for (int i = 0; i < count; i++) results[i] = RANDOM.nextInt(1, sides + 1);
        return results;
    }

    static int sum(int... values) {
        int total = 0;
        for (int value : values) total += value;
        return total;
    }

    static double average(int... values) {
        return values.length == 0 ? 0.0 : (double) sum(values) / values.length;
    }

    static void printRolls(int[] values) {
        for (int value : values) System.out.print("[" + value + "] ");
        System.out.println();
    }
}
方法设计习惯一个方法只做一件能被准确命名的事；计算方法尽量 return 数据，让 main 决定怎样输出。这样比在所有方法里直接 println 更容易测试。
自检：能否定义 int area(int,int) 和 double area(int,int)？
不能。调用时参数列表完全相同，编译器不能仅根据期望返回类型选择方法。必须改变参数类型/数量或方法名。

数组、搜索、二维数组与小游戏数据 #

用固定长度的同类型容器管理测验、棋盘和老虎机数据。

5.1 数组的类型、长度与索引

数组在创建时确定长度，保存同一种类型，索引从 0 到 length - 1。int[] scores = new int[5] 会得到五个初始为 0 的槽位；array initializer 可直接写 {...}。访问越界会抛出 ArrayIndexOutOfBoundsException，不会像 Python 一样允许 array[-1] 访问最后一项。

int[] scores = {84, 91, 76, 95};
int total = 0;
for (int score : scores) total += score;
double average = (double) total / scores.length;

for (int i = 0; i < scores.length; i++) {
    System.out.printf("scores[%d] = %d%n", i, scores[i]);
}
Python 对照固定长度
Python list 可自由 append 且可混合类型；Java array 长度固定、元素类型固定。需要动态长度时，第 9 章使用 ArrayList。

5.2 从输入填充与线性搜索

填充数组时用索引循环，因为需要写入指定位置；只读遍历时 enhanced for 更清楚。无序数组中查找目标，最坏要查看全部 (n) 个元素，时间为 (O(n))。找到后立刻 break，并用 -1 表示“没有合法索引”。

static int indexOf(String[] items, String target) {
    for (int i = 0; i < items.length; i++) {
        if (items[i].equalsIgnoreCase(target)) return i;
    }
    return -1;
}

5.3 二维数组

char[][] board 是“元素也是 char[] 的数组”，因此每一行理论上可以不同长度。规则矩阵通常保持 rectangular，但循环条件仍应写 board[row].length 而不是假定所有行都等于 board[0].length。

char[][] board = {
    {'X', '.', 'O'},
    {'.', 'X', '.'},
    {'O', '.', 'X'}
};
for (int row = 0; row < board.length; row++) {
    for (int col = 0; col < board[row].length; col++)
        System.out.print(board[row][col] + " ");

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        String[] questions = {
            "Which keyword creates a subclass?",
            "What is the first array index?",
            "Which method compares String content?"
        };
        String[][] choices = {
            {"A. extends", "B. import", "C. package"},
            {"A. 1", "B. 0", "C. -1"},
            {"A. ==", "B. compare", "C. equals"}

        for (int i = 0; i < questions.length; i++) {
            System.out.println("\n" + questions[i]);
            for (String choice : choices[i]) System.out.println(choice);

类、对象、构造器、static 与 toString #

从“数据散落在变量里”转向“对象负责维护自己的状态和行为”。

6.1 类是蓝图，对象是实例

类定义 fields 和 methods；new 调用 constructor 创建对象。每个对象有自己的 instance fields，而 static field 属于整个类、被所有实例共享。构造器名称与类相同且没有返回类型——连 void 也不能写。

class Book {
    private String title;
    private String author;
    private int pages;
    private static int bookCount = 0;

    Book(String title, String author, int pages) {
        this.title = title;
        this.author = author;
        this.pages = pages;
        bookCount++;
    }

    Book(String title, String author) { // overloaded constructor
        this(title, author, 0);          // 必须是构造器第一条语句
    }

    boolean isLongRead() { return pages >= 400; }
    static int getBookCount() { return bookCount; }

    @Override
    public String toString() {
        return "%s by %s (%d pages)".formatted(title, author, pages);
    }
}
Python 对照self 与 this
Python 用 self.title；Java 用 this.title。Java 方法签名不显式写 self/this 参数，编译器为 instance method 提供当前对象。

6.2 this、构造器重载与合法状态

this.title = title 左边是字段、右边是参数。多个构造器可以提供不同创建方式，但应把公共初始化委托给一个主要构造器，避免规则复制。对象创建完成时就应处于合法状态；页数为负应立即拒绝，而不是等到打印时再修补。

6.3 static 何时合理

Math.sqrt 不依赖某个 Math 对象，所以是 static。全班共享的对象计数也可 static。学生姓名、分数等每个对象不同的数据不能 static，否则创建第二个对象会覆盖所有对象看到的值。static method 没有某个具体 this，因此不能直接访问 instance field。

6.4 对象数组与 toString

public class Main {
    public static void main(String[] args) {
        Book[] shelf = {
            new Book("The Hobbit", "J. R. R. Tolkien", 310),
            new Book("Dune", "Frank Herbert", 412),
            new Book("Short Stories", "Various")

继承、super、方法覆写、抽象类与接口 #

表达“is-a”关系，并把共同规则与可变能力分开。

7.1 extends 与 is-a

若 Dog extends Animal，Dog 是一种 Animal，可以继承可见字段/方法并覆写行为。继承应表达真正的 is-a，而不是只为了少写几行代码。Java 类只支持单继承，但一个类可以实现多个接口。

abstract class Shape {
    private final String color;

    protected Shape(String color) { this.color = color; }
    public String color() { return color; }
    public abstract double area();

    public void describe() {
        System.out.printf("%s shape, area %.2f%n", color, area());
    }
}

class Circle extends Shape {
    private final double radius;
    Circle(String color, double radius) {
        super(color);
        if (radius < 0) throw new IllegalArgumentException();
        this.radius = radius;
    }
    @Override public double area() { return Math.PI * radius * radius; }
}

7.2 super 与构造顺序

子类构造器必须先构造父类部分；super(...) 若显式出现，必须是第一条语句。super.method() 可调用父类版本。private 字段不能由子类直接访问，应通过 protected/public 方法维护封装，而不是为了继承把所有字段改成 public。

7.3 Override 不是 Overload

概念发生位置方法签名选择时机
overload同一类或继承层次同名、参数列表不同编译时根据参数选择
override子类重新实现父类方法参数相同、返回类型兼容运行时根据实际对象选择

始终写 @Override，让编译器检查拼写和签名。如果误写 double areas() 而不是 area()，注解会立即揭示它没有覆写。

7.4 抽象类与接口

abstract class 可以保存状态、提供构造器与部分实现，但不能直接实例化。interface 更像能力契约：实现类承诺提供指定行为。下面的 Printable 可被 Shape 之外的其他类实现。

interface Printable {
    String printableText();
}

class Rectangle extends Shape implements Printable {
    private final double width, height;
    Rectangle(String color, double width, double height) {
        super(color); this.width = width; this.height = height;
    }
    @Override public double area() { return width * height; }
    @Override public String printableText() {
        return "Rectangle[" + color() + ", area=" + area() + "]";
    }
}
Python 对照显式契约
Python 常依赖 duck typing；Java interface 在编译时说明对象必须提供哪些方法。抽象类更适合共享状态/实现，接口更适合跨不同类表达共同能力。
避免错误继承Car extends Engine 不合理：汽车不是发动机。汽车“拥有”发动机，应使用 composition；第 8 章专门处理。
自检：为何 Shape shape = new Shape(...) 不合法？
Shape 是抽象类，可能包含尚未实现的 abstract 方法。只能实例化完成这些方法的具体子类。

多态、运行时选择、封装、聚合与组合 #

用统一类型处理不同对象，同时清楚对象的拥有关系与生命周期。

8.1 多态：同一个接口，多种行为

父类/接口变量可以引用子类对象。编译器根据变量的声明类型检查“能否调用”，JVM 根据实际对象选择被覆写的方法，这就是 runtime polymorphism。它让循环无需大量 if(type == ...)。

interface SoundMaker { void makeSound(); }
class Dog implements SoundMaker {
    @Override public void makeSound() { System.out.println("Woof"); }
}
class Cat implements SoundMaker {
    @Override public void makeSound() { System.out.println("Meow"); }
}

public class Main {
    public static void main(String[] args) {
        SoundMaker[] animals = {new Dog(), new Cat()};
        for (SoundMaker animal : animals) animal.makeSound();
    }
}

runtime polymorphism 也可由用户选择具体对象后统一使用。向下转型只有在确实需要子类特有功能、并确认 instanceof 后才做；频繁转型通常说明接口设计不完整。

8.2 getters、setters 与封装

private 字段防止外部随意破坏状态。getter 不只是“公开字段的另一种写法”，setter 也不是每个字段必须拥有：不可变字段只给 getter；可变字段的 setter 负责验证。

class BankAccount {
    private final String owner;
    private double balance;
    BankAccount(String owner, double opening) {
        if (opening < 0) throw new IllegalArgumentException();
        this.owner = owner; this.balance = opening;
    }
    public String getOwner() { return owner; }
    public double getBalance() { return balance; }
    public void deposit(double amount) {
        if (amount <= 0) throw new IllegalArgumentException();
        balance += amount;
    }
}

8.3 Aggregation 与 composition

关系生命周期例子Java 表达
aggregation部分可独立存在，可被共享Club 有 members；学生离开 club 仍存在构造器接收已有对象/集合
composition部分由整体创建和拥有House 有 Room；Room 属于该 House整体内部 new 并控制生命周期

两者都是 has-a。不要仅凭 Java 代码里有没有 new 就下结论，关键是领域语义：部分是否能在整体之外有独立身份。

8.4 完整示例：订单、顾客和订单行

class Customer { // 可独立于某张订单存在：aggregation
    private final String name;
    Customer(String name) { this.name = name; }
    String name() { return name; }
}
class Order {
    private final Customer customer;
    private final Line[] lines = new Line[10];
    private int size = 0;
    private static class Line { // 由 Order 创建和拥有：composition
        final String item; final double price;
        Line(String item, double price) { this.item = item; this.price = price; }
    }
    Order(Customer customer) { this.customer = customer; }
    void add(String item, double price) {
        if (price < 0) throw new IllegalArgumentException();
        if (size == lines.length) throw new IllegalStateException("order is full");
        lines[size++] = new Line(item, price);
    }
    double total() {
        double sum = 0;
        for (int i = 0; i < size; i++) sum += lines[i].price;
        return sum;
    }
    void print() {
        System.out.printf("%s's order: %.2f%n", customer.name(), total());
    }
}
public class Main {
    public static void main(String[] args) {
        Customer maya = new Customer("Maya");
        Order order = new Order(maya);
        order.add("Notebook", 4.50); order.add("Pen", 1.20); order.print();
    }
}
示例范围这里沿用已学过的固定数组保存最多十个订单行，不提前引入下一章的 ArrayList。重点是 Customer 与 Order 的独立生命周期、Line 的内部拥有关系。
自检：为什么“所有字段都生成 setter”会削弱封装？
外部可以绕过对象行为随意改状态，例如直接把余额设成负数。更好的接口是 deposit/withdraw 等表达规则的方法，不可变值不提供 setter。

包装类、自动装箱与 ArrayList #

当长度需要变化时，用泛型集合管理对象。

9.1 primitive 与 wrapper

Java 的八种 primitive 有对应包装类：int → Integer、double → Double、boolean → Boolean、char → Character 等。集合的泛型参数必须是引用类型，所以写 ArrayList<Integer>，不能写 ArrayList<int>。编译器常自动完成 autoboxing/unboxing。

Integer boxed = 42;       // autoboxing: int → Integer
int plain = boxed;        // unboxing: Integer → int
int number = Integer.parseInt("2026");
String text = Double.toString(3.14);
boolean digit = Character.isDigit('7');
null unboxingInteger value = null; int n = value; 编译可以通过，但运行时会抛出 NullPointerException。wrapper 还应使用 equals 比较内容，不要依赖 == 的缓存细节。

9.2 ArrayList 的核心操作

ArrayList<E> 是可变长度的对象序列。它在内部使用数组，容量不足时自动扩容。add、get、set、remove、contains、size 是本章重点。尾部追加通常很快；在开头插入/删除要移动后续元素。

目的写法注意
追加names.add("Ava")size 增加 1
读取names.get(0)仍从 0 开始
替换names.set(0,"Mia")不改变 size
按索引删除names.remove(0)后续左移
按对象删除names.remove("Mia")删除第一个相等项

9.3 Integer 删除的歧义

numbers.remove(2) 会把 2 当作 index；若要删除值 2，写 numbers.remove(Integer.valueOf(2))。这是 method overloading 与 autoboxing 共同造成的典型初学者陷阱。

9.4 完整示例：动态待办清单

import java.util.ArrayList;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        ArrayList<String> tasks = new ArrayList<>();

        while (true) {
            System.out.print("add/list/remove/quit: ");
            String command = scanner.nextLine().trim().toLowerCase();
            switch (command) {
                case "add" -> {
                    System.out.print("Task: ");
                    String task = scanner.nextLine().trim();
                    if (!task.isBlank()) tasks.add(task);
                }
                case "list" -> {
                    for (int i = 0; i < tasks.size(); i++)
                        System.out.printf("%d. %s%n", i + 1, tasks.get(i));
                }
                case "remove" -> {
                    System.out.print("Number: ");
                    int index = Integer.parseInt(scanner.nextLine()) - 1;
                    if (index >= 0 && index < tasks.size()) tasks.remove(index);
                }
                case "quit" -> { return; }
                default -> System.out.println("Unknown command");
            }
        }
    }
}
Python 对照list 与 ArrayList
两者都能动态增删，但 Java 必须声明元素类型，长度是 size()，索引读取用 get(i)。Java array 的长度则是字段 length。
自检：ArrayList<Integer> values; values.remove(1); 删除什么？
调用 remove(int index)，删除索引 1 的元素。删除数值 1 要传 Integer.valueOf(1)。

异常处理、文件读写与日期时间 #

让音乐清单、Hangman 词库和学习日志能够安全持久化。

10.1 异常不是普通分支的替代品

exception 表示正常流程无法继续。checked exception（如某些 I/O 错误）要求捕获或声明；runtime exception 常表示编程错误或非法输入。try 包围可能失败的代码，catch 处理明确异常，finally 无论成功失败通常都会执行。

try {
    int age = Integer.parseInt(text);
    if (age < 0) throw new IllegalArgumentException("age cannot be negative");
} catch (NumberFormatException e) {
    System.out.println("Please enter a whole number.");
} catch (IllegalArgumentException e) {
    System.out.println(e.getMessage());
}

catch 应尽量具体。空的 catch (Exception e) {} 会吞掉原因，让程序看似继续却处于错误状态。输入边界可以给用户重试；真正的文件损坏要清楚报告。

10.2 try-with-resources

文件、Scanner 等资源使用后必须关闭。实现 AutoCloseable 的资源放在 try 括号里，会在退出时自动关闭，即使发生异常也不泄漏。

import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.StandardOpenOption;

Path file = Path.of("notes.txt");
Files.writeString(file, "Java arrays reviewed\n",
        StandardOpenOption.CREATE, StandardOpenOption.APPEND);
String content = Files.readString(file);
System.out.println(content);

现代小文件可用 Files.readString/writeString/readAllLines；大文件应逐行流式处理，避免一次装入内存。路径相对当前 working directory，不一定等于源文件所在目录。字符编码建议显式使用 UTF-8。

10.3 日期时间 API

LocalDate 表示无时区日期，LocalTime 表示时间，LocalDateTime 表示本地日期时间；跨时区时用 ZonedDateTime/Instant。这些类不可变，调用 plusDays 会返回新对象。

import java.time.LocalDateTime;
import java.time.format.DateTimeFormatter;

LocalDateTime now = LocalDateTime.now();
DateTimeFormatter format = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm");
System.out.println(now.format(format));

10.4 完整示例：带时间的学习日志

import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.StandardOpenOption;
import java.time.LocalDateTime;
import java.time.format.DateTimeFormatter;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        Path log = Path.of("study-log.txt");
        System.out.print("What did you study? ");
        String topic = scanner.nextLine().trim();
        if (topic.isBlank()) {
            System.out.println("Nothing saved."); return;
        }
        String stamp = LocalDateTime.now().format(
                DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm"));
        try {
            Files.writeString(log, stamp + " | " + topic + System.lineSeparator(),
                    StandardCharsets.UTF_8,
                    StandardOpenOption.CREATE, StandardOpenOption.APPEND);
            System.out.println("Saved to " + log.toAbsolutePath());
        } catch (IOException e) {
            System.err.println("Could not save log: " + e.getMessage());
        }
    }
}

泛型、HashMap 与 enum #

让类型安全的容器表达“键 → 值”关系和有限状态集合。

11.1 泛型在编译期保护类型

泛型类或方法用类型参数（常见 T、E、K、V）描述“算法相同，数据类型由使用者决定”。它减少强制类型转换，并让错误更早出现。

class Box<T> {
    private T value;
    Box(T value) { this.value = value; }
    T get() { return value; }
    void set(T value) { this.value = value; }
}

static <T> void printArray(T[] items) {
    for (T item : items) System.out.println(item);
}

Box<String> 和 Box<Integer> 复用同一实现。泛型不能直接写 primitive 参数，所以使用 wrapper。不要使用 raw type Box box，它会丢失类型检查并产生警告。

11.2 HashMap 表示键值映射

HashMap<K,V> 用唯一 key 查找 value。常用方法有 put、get、getOrDefault、containsKey、remove、keySet、entrySet。它不保证按插入或字母顺序遍历；需要排序时另行排序或选择合适结构。

String sentence = "java is clear when java types are clear";
HashMap<String, Integer> counts = new HashMap<>();
for (String word : sentence.split(" ")) {
    counts.put(word, counts.getOrDefault(word, 0) + 1);
}
for (var entry : counts.entrySet())
    System.out.println(entry.getKey() + " = " + entry.getValue());

11.3 enum 表达有限选择

若状态只能是少数固定值，enum 比自由字符串安全：编译器阻止拼写错误，switch 还能检查枚举分支。enum 不只是常量列表，也能有字段、构造器和方法。

enum Priority {
    LOW(1), MEDIUM(2), HIGH(3);
    private final int weight;
    Priority(int weight) { this.weight = weight; }
    int weight() { return weight; }
}

11.4 完整示例：库存表

import java.util.HashMap;
import java.util.Map;

enum StockState { OUT, LOW, OK }

public class Main {
    static StockState stateOf(int quantity) {
        if (quantity == 0) return StockState.OUT;
        if (quantity < 5) return StockState.LOW;
        return StockState.OK;
    }
    public static void main(String[] args) {
        Map<String, Integer> stock = new HashMap<>();
        stock.put("pen", 12); stock.put("notebook", 3); stock.put("eraser", 0);
        stock.put("pen", stock.getOrDefault("pen", 0) + 5);

        for (Map.Entry<String, Integer> entry : stock.entrySet()) {
            System.out.printf("%-10s %3d  %s%n",
                    entry.getKey(), entry.getValue(), stateOf(entry.getValue()));
        }
    }
}
Python 对照dict 与 enum
HashMap 类似 Python dict，但 key/value 类型显式。Java enum 是真正的类型，不应退回字符串 "HGIH" 这类运行时才发现的拼写。
不存在不等于值为 nullmap.get(key) 返回 null 可能表示 key 不存在，也可能 key 映射到 null。用 containsKey 区分，或者设计时不允许 null value。
自检：HashMap 为什么不能直接承诺输出顺序？
它按哈希 bucket 组织数据，遍历顺序是实现细节，可能随容量或内容改变。若输出必须稳定，要显式排序 key 或使用有顺序契约的结构。

匿名类、TimerTask、线程与多线程 #

让计时器和后台任务并发执行，同时避免共享状态错误。

12.1 匿名类是一次性实现

若接口实现只使用一次，可以在创建对象的位置给出 anonymous class。它没有单独类名，适合短小回调；逻辑变长时应提取为命名类。lambda 是只有一个抽象方法的 functional interface 的更简洁写法。

Runnable namedByBehavior = new Runnable() {
    @Override public void run() {
        System.out.println("Anonymous task running");
    }
};
Runnable lambdaTask = () -> System.out.println("Lambda task running");

12.2 Timer 与 TimerTask

Timer 安排任务在未来或周期执行，TimerTask 描述任务。经典 countdown 中，每秒递减一次，结束后必须 cancel()，否则非 daemon timer thread 可能让程序继续存活。Timer 使用单线程：某次任务卡住会推迟后续任务。

import java.util.Timer;
import java.util.TimerTask;

public class Main {
    public static void main(String[] args) {
        Timer timer = new Timer();
        timer.scheduleAtFixedRate(new TimerTask() {
            int seconds = 5;
            @Override public void run() {
                if (seconds > 0) System.out.println(seconds--);
                else { System.out.println("Go!"); cancel(); timer.cancel(); }
            }
        }, 0, 1_000);
    }
}

12.3 Thread、Runnable、start 与 join

thread 是独立执行路径。调用 run() 只是在当前线程执行普通方法；调用 start() 才创建新执行路径。join() 让当前线程等待另一个线程结束。执行先后由 scheduler 决定，所以不要假设两个线程的打印顺序固定。

public class Main {
    public static void main(String[] args) throws InterruptedException {
        Thread homework = new Thread(() -> doTask("Homework", 3));
        Thread revision = new Thread(() -> doTask("Revision", 3));
        homework.start();
        revision.start();
        homework.join();
        revision.join();
        System.out.println("Both tasks finished.");
    }
    static void doTask(String name, int steps) {
        for (int i = 1; i <= steps; i++) {
            System.out.printf("%s step %d%n", name, i);
            try { Thread.sleep(200); }
            catch (InterruptedException e) {
                Thread.currentThread().interrupt(); return;
            }
        }
    }
}

12.4 共享可变状态与 race condition

counter++ 不是不可分割的一步，而是读取、加一、写回。两个线程可能读到同一个旧值，导致更新丢失。优先让线程处理彼此独立的数据；必须共享计数时可用 AtomicInteger，更复杂临界区使用 synchronized 或更高层并发工具。

import java.util.concurrent.atomic.AtomicInteger;

AtomicInteger completed = new AtomicInteger();
Runnable work = () -> {
    // do work...
    completed.incrementAndGet();
};
线程停止策略不要使用已经废弃且不安全的 Thread.stop()。用 interrupt 请求停止，在 catch 中恢复中断标志，并让任务安全返回。计时程序结束时取消 Timer。
Python 对照调度与共享状态
两种语言的线程都不保证打印顺序。Java 的共享字段同样会发生 race condition；“这次跑对了”不是线程安全证明。
自检：为什么调用 thread.run() 看起来能工作，却没有并发？
run 是普通方法调用，仍在当前线程执行。只有 start 会让 JVM 建立新线程并随后调用其 run。
